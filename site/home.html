Running in this repository's own player — the C console compiled to WebAssembly, served from this page and nowhere else. The same code, compiled for ESP32 instead, draws the same pixels on a handheld.

{{DEMOTABS}}

Under 400 KB of player and cart per demo. Open it full screen ↗ — and python3 moy.py export turns any cart into exactly this.

Coming from PICO-8? moy demo fetches Celeste Classic, ports it and plays it in this same player — one command, on your machine, nothing to set up first.

The palette — 64 entries; 0–15 are PICO-8's, byte-exact, so a converted cart keeps its colours. The table is data, not prose: palette.json.
