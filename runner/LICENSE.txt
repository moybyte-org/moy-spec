moy web player -- licence and notices
=====================================

These files (index.html, player.js, moy.mjs, moy.wasm) are the moy web player.
`moy export` copies them beside a cart to make a playable web bundle, so this
notice travels with them: moy.wasm has Lua and Emscripten's runtime compiled
into it, and both are MIT-licensed, which requires their notices to accompany
every copy.

If you are reading this inside an exported game: the LICENCE OF THE GAME IS NOT
THIS FILE. The cart (carts.json here) belongs to whoever wrote it, under
whatever terms they chose -- and a cart converted from a PICO-8 BBS cart carries
the original's licence, which defaults to CC BY-NC-SA 4.0. This file covers the
player around it.
